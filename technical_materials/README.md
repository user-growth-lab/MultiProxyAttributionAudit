# Technical Appendix

`technical_appendix.pdf` is the single canonical anonymous appendix. It
contains complete proofs, the controlled-benchmark design and chronology, the
Amazon evaluation protocol, extended diagnostics, and the full human-readable
aggregate tables and figures.

The appendix is prebuilt so a reviewer does not need a TeX environment. Its
LaTeX sources and duplicate table or figure fragments are intentionally
excluded. The root manifest and checksum file bind the released PDF.
