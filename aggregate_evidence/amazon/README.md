# Aggregate Amazon Evidence

`amazon_aggregate_results.json` contains selected machine-readable aggregate
results corresponding to the Amazon tables in the technical appendix. The
appendix is the complete human-readable reporting surface; this JSON is a
convenience for inspecting numeric arrays, not a separate or larger claim set.

The file contains no user-level rows, identifiers, raw reviews, prompts, model
responses, parsed profiles, held-out records, local paths, source-file hashes,
or internal release state. The future-rated surface is an observable
comparator rather than latent-preference ground truth.
